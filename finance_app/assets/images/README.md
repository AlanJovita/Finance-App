# Instruções para adicionar o logo

Para que o logo apareça na tela de login, salve a imagem do logo como:

**`logo.png`**

nesta mesma pasta (`assets/images/`).

Se você não adicionar o logo, um ícone padrão será exibido automaticamente.

## Formato recomendado:
- Formato: PNG (com fundo transparente de preferência)
- Tamanho: 512x512 pixels ou maior (será redimensionado automaticamente)
- Nome do arquivo: `logo.png`
